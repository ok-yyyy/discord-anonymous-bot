# discord-anonymous-bot

チャンネル内に匿名でメッセージを投稿できるDiscord Botです。

チャンネルに設置されたパネルのボタンからモーダルを開き、入力した内容をWebhook経由で投稿します。
投稿されたメッセージに送信者の情報は残らず、投稿者ごとに匿名の表示名とアバターが割り当てられます。

## 特徴

- **パネル + モーダル方式** — スラッシュコマンドの履歴に内容が残りません
- **日替わりの匿名名** — 表示名とアバターはユーザIDと日付から導出され、同じ日の同じ人は同じ名前になります (日付が変わると変わります)
- **逆引き耐性** — 表示名は`ANONYMOUS_SALT`を鍵としたHMAC-SHA256から生成されるため、saltを知らない第三者がユーザIDから総当たりで逆引きすることはできません
- **メンション無効化** — 匿名メッセージ内の`@everyone`やユーザ/ロールへのメンションはすべて無効化されます

## コマンド

| コマンド | 説明                                                          |
| -------- | ------------------------------------------------------------- |
| `/help`  | Botの使い方を表示します                                       |
| `/setup` | 現在のチャンネルに送信パネルを設置します (既定では管理者のみ) |
| `/ping`  | 疎通確認をします                                              |

## 必要なもの

- Go 1.26以上
- Docker / Docker Compose
- Discord Botのトークン

## セットアップ

`.env.example`をコピーして`.env`を作成し、値を設定します。

| 環境変数            | 説明                         |
| ------------------- | ---------------------------- |
| `DISCORD_BOT_TOKEN` | Discord Botのトークン        |
| `ANONYMOUS_SALT`    | 匿名名の導出に使う秘密のsalt |

## 実行

```sh
docker compose up -d --build
```

ログの確認と停止:

```sh
docker compose logs -f
docker compose down
```

## 使い方

1. 匿名メッセージを使いたいチャンネルで`/setup`を実行します。Webhookが用意され、送信パネルが設置されます。
   `/setup`は既定では管理者のみ実行できます。サーバー設定から他のロールやメンバーに許可することもできます。
2. パネルの **メッセージを送信** ボタンを押し、フォームに内容を入力して送信します。
3. 匿名メッセージが投稿され、パネルはチャンネルの最下部に再設置されます。
