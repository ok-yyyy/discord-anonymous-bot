# プライバシーポリシー

Discord Bot「匿名メッセージ投稿Bot」 (以下「本Bot」) が取り扱う情報について定めます。

最終更新日: 2026-09-30

## 受け取る情報

| 情報                      | 用途                         |
| ------------------------- | ---------------------------- |
| 利用者のDiscordユーザーID | 匿名の表示名とアイコンの導出 |
| サーバーID・チャンネルID  | 投稿先の判定                 |
| 入力されたメッセージ本文  | 投稿内容                     |

メールアドレス、IPアドレス、Discordアカウントのパスワードは受け取りません。\
Cookieやアクセス解析も使用していません。

## 保存しないこと

**誰が何を投稿したかを記録していません。**\
表示名とアイコンはユーザーIDと日付とsaltから投稿のたびに計算しており、ユーザーIDもハッシュ値も保存していません。\
日付を含めるため、表示名とアイコンは毎日変わります。

例外として、次の期間だけ情報が残ります。\
いずれも期間の経過により自動的に削除されます。

| 対象                                          | 期間                                        |
| --------------------------------------------- | ------------------------------------------- |
| 投稿処理の待ち行列 (AWS SQS)                  | 処理完了と同時に削除。滞留した場合も最大4日 |
| 処理に失敗したメッセージ (デッドレターキュー) | **最大14日**。本文とユーザーIDを含みます    |
| 実行ログ (AWS CloudWatch Logs)                | 1か月。本文とユーザーIDは記録していません   |

なお、**投稿されたメッセージ自体はDiscord上に残ります。**\
これは本Botの管理下になく、[Discordのプライバシーポリシー](https://discord.com/privacy)が適用されます。\
削除したい場合は、サーバー管理者による当該メッセージの削除が必要です。

## 匿名性の限界

記録していないため、**記録をたどって投稿者を知ることはできません。**\
ただし次の点にご留意ください。

- **運営者も投稿者を照会する手段を持ちません**\
  そのための機能は用意しておらず、運用としても行いません
- **処理に失敗した投稿は、本文とユーザーIDが最大14日残ります**
- **表示名は重複しえます**\
  同じ表示名でも別の利用者であることがあります
- **本文の内容から書き手が推測されることがあります**\
  固有の事情や文体は、本Botでは隠せません

秘匿性が重要な内容の投稿には利用しないでください。

## 第三者への提供

情報を販売・貸与することはありません。\
機能の提供に必要な範囲で、Discord、Amazon Web Services (実行環境) 、DiceBear (アイコン画像の生成) を利用しています。\
DiceBearに渡すのはハッシュから導出した文字列だけで、画像の取得はDiscord側が行います。

法令に基づく開示請求があった場合は、これに応じることがあります。

## 本ポリシーの変更

予告なく変更することがあります。\
変更後の内容は本ページに掲載した時点から適用されます。
