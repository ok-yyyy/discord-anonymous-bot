# プライバシーポリシー

本ポリシーは、Discord Bot「匿名メッセージ Bot」 (以下「本Bot」) が取り扱う情報について定めるものです。

最終更新日: 2026-09-30

## 1. 基本方針

**本Botは利用者の情報を保存するためのデータベースを持ちません。**

## 2. 受け取る情報

利用者が本Botを操作したとき、Discordから次の情報が送られます。

| 情報                      | 用途                         |
| ------------------------- | ---------------------------- |
| 利用者のDiscordユーザーID | 匿名の表示名とアイコンの導出 |
| サーバーID・チャンネルID  | 投稿先の判定                 |
| 入力されたメッセージ本文  | 投稿内容                     |

これらを恒久的に保存することはありません。
また、メールアドレス、IPアドレス、Discordアカウントのパスワードを受け取ることはありません。

## 3. 匿名の表示名とアイコンの生成方法

利用者のDiscordユーザーID、当日の日付 (UTC) 、および運営者が保持する秘密の文字列 (salt) を連結し、
SHA-256でハッシュ化した値から表示名とアイコンを決めます。

- **ユーザーIDもハッシュ値も保存しません。** 投稿のたびに計算します
- 日付を含めるため、**表示名とアイコンは毎日変わります**。
  前日の投稿と同一人物であることを、投稿の見た目から結び付けることはできません

## 4. 保存期間

| 対象                                          | 期間                                        |
| --------------------------------------------- | ------------------------------------------- |
| 投稿処理の待ち行列 (AWS SQS)                  | 処理完了と同時に削除。滞留した場合も最大4日 |
| 処理に失敗したメッセージ (デッドレターキュー) | **最大14日**                                |
| 実行ログ (AWS CloudWatch Logs)                | 1か月                                       |

**処理に失敗した場合のみ**、原因調査のために受信内容がデッドレターキューに最大14日保持されます。
ここには利用者のDiscordユーザーIDとメッセージ本文が含まれます。
期間の経過により自動的に削除されます。

実行ログには、動作状況とエラーだけを記録しています。
利用者のDiscordユーザーID、メッセージ本文、salt、認証トークンは記録していません。

なお、**投稿されたメッセージ自体はDiscord上に残ります。**
これは本Botの管理下にはなく、[Discord のプライバシーポリシー](https://discord.com/privacy)が適用されます。
削除したい場合は、サーバー管理者による当該メッセージの削除が必要です。

## 5. 第三者への提供

情報を販売・貸与することはありません。
機能の提供に必要な範囲で、次のサービスを利用しています。

- **Discord** — メッセージの投稿先です
- **Amazon Web Services (AWS)** — 本Botの実行環境です (Lambda, SQS, CloudWatch Logs)
- **DiceBear** — アイコン画像の生成に利用します
  渡すのはハッシュから導出した文字列 (seed) のみで、ユーザーIDなどは含みません
  画像の取得はDiscord側が行うため、本BotからDiceBearへの通信は発生しません

法令に基づく開示請求があった場合は、これに応じることがあります。

## 6. 匿名性の限界

誰が何を投稿したかを記録していないため、**記録をたどって投稿者を知ることはできません。**
ただし次の点にご留意ください。

- **運営者も投稿者を照会する手段を持ちません。**
  投稿者を確認するための機能は用意しておらず、運用としても行いません。
  ただし仕組み上、saltとサーバーのメンバー一覧から推定を試みること自体は可能です
- **処理に失敗した投稿は、本文とユーザーIDがデッドレターキューに最大14日残ります** (第4項)
- **表示名は重複しえます。**
  組み合わせ数に限りがあるため、同じ表示名でも別の利用者であることがあります
- **本文の内容から書き手が推測されることがあります。**
  固有の事情や文体は、本Botでは隠せません

秘匿性が重要な内容の投稿には利用しないでください。

## 7. Cookie・アクセス解析

本BotはCookieを使用せず、アクセス解析ツールも導入していません。

## 8. 本ポリシーの変更

本ポリシーは予告なく変更することがあります。
変更後の内容は、本ページに掲載した時点から適用されます。
